# UUSD Network Client (Telegram Mini App)

React + Vite + TypeScript

**Data layer:** All data goes through REST API to MySQL (no Firebase, no localStorage for wallet/data).

## Setup

```bash
cp .env.example .env
# Set VITE_API_URL=http://localhost:3001/api  (or your Railway backend URL)
npm install
npm run dev
```

Admin: `/admin` -> admin / uusdadmin2026
